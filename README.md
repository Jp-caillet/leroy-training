# leroy-training

## Installation

```bash
npm install
```

## Lint (ESLint)

| Commande | Effet |
|---|---|
| `npm run lint` | Analyse tout le projet et affiche les erreurs |
| `npm run lint:fix` | Corrige automatiquement les erreurs qui peuvent l'être |

## Formatage (Prettier)

| Commande | Effet |
|---|---|
| `npm run format:check` | Liste les fichiers mal formatés, sans les modifier |
| `npm run format` | Reformate tous les fichiers |

Dans VS Code, avec les extensions **ESLint** et **Prettier** installées, le formatage et les corrections ESLint s'appliquent automatiquement à chaque sauvegarde.
